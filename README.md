# ha-myenecle
<img src="icon.png" alt="Icon" width="150">
Unofficial add-on for Enecle (エネクル) gas monitoring service.

## Features
- Update current month power usage and cost.
- Updata last month power usage and cost.

## Installation

- Add-on store 
- Add to your Respositories and download
